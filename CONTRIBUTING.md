# Contributing to JARVIS

We love your input! We want to make contributing to this project as easy and transparent as possible.

## Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests in `tests/`.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`pytest`).
5. Make sure your code lints (`flake8`).

## Coding Style
- We use `black` for formatting and `isort` for import sorting.
- Please run `python -m black .` and `python -m isort .` before committing.
- Use Python 3 type hints where possible.
