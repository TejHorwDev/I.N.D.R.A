Absolute Perception

AGNI's architecture ensures INDRA doesn't just read text—it truly sees your world. Designed explicitly for gamers and creators.

■ screen_process

Captures real-time visual input. Configurable to use 'screen' to capture display across multiple monitors, or 'camera' for the system default webcam.

■ game_scanner

Scans the system for installed games via Registry and common game directories (Steam, Epic Games, Xbox Game Pass, Riot Games) to populate the Game Library float widget.

■ window_controller

Manages active application windows on the desktop. Used to seamlessly switch contexts and organize the visual workspace based on user requests.

■ game_updater

Automated tool to check and initiate background updates for the games detected by the game_scanner, ensuring the library is always ready to play.

■ OpenCV Compression

Raw 4K frames are instantly compressed and scaled using OpenCV to eliminate bandwidth bottlenecks during transmission to the vision model.

■ Bounding Box Generation

AGNI processes the screen in real-time, instantly drawing mathematical coordinate bounding boxes around UI elements so INDRA knows exactly where to click.
